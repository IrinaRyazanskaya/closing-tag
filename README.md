# Закрывающий тег ✅

Одностраничный интерактивный материал о пути в веб-разработку: адаптивная вёрстка, переключение тем
и живые лайки в стиле ретро-интерфейсов.

## ✨ Ключевая функциональность

- Три темы оформления: тёмная, светлая и "как в системе". Выбор хранится в `localStorage`.
- Анимированное сердце в формате SVG и кнопка "Нравится/Не нравится" с синхронизированным текстом.
- Адаптивные размеры шрифтов через `clamp()` и аккуратная подстройка контента под ширину экрана.
- Отложенная загрузка изображений и цветовые фильтры (`contrast`, `invert`, `hue-rotate`) для ярких
  акцентов.
- Элементы управления с заметным фокусом и ARIA-подписями для доступности.
- Вариативные шрифты (`Inter`, `Press Start 2P`) и продуманное использование `mix-blend-mode`.

## 🛠️ Использованные технологии

- **Разметка** HTML5, CSS3, семантическая вёрстка.
- **Поведение:**: Чистый JavaScript, работа с `localStorage`.
- **Инструменты:** Node.js, NPM, ESLint, Stylelint, Prettier.
- **Оформление:** Адаптивный дизайн, CSS-переменные, кросс-браузерные стили, анимации, вариативные
  шрифты, SVG.

## 🚀 Установка и запуск

1. Установите Node.js версии 22 LTS или новее.
2. Склонируйте репозиторий и перейдите в директорию проекта:

   ```bash
   git clone https://github.com/IrinaRyazanskaya/closing-tag.git
   cd closing-tag
   ```

3. Установите зависимости:

   ```bash
   npm install
   ```

4. Запустите локальный сервер и откройте проект в браузере:

   ```bash
   npm run serve
   ```

   По умолчанию сайт будет доступен по адресу http://localhost:3000.

5. При необходимости запускайте команды для улучшения качества кода:

   ```bash
   npm run format      # запуск форматтера
   npm run lint        # запуск линтеров
   npm run lint-fix    # автоматическое исправление ошибок
   ```

## 💡 Что сделано

- Темы на CSS-переменных и сохранение выбора пользователя в `localStorage`.
- Адаптивная типографика через `clamp()` и ретро-стилистика на вариативных шрифтах.
- Интерактивная SVG-анимация и аккуратная работа с классами для плавного взаимодействия.
- Основные приёмы доступности: видимый фокус, aria-label, достаточный контраст, управление с
  клавиатуры.
- Автоматическая проверка качества через `ESLint`, `Stylelint`, `Prettier`.

## 📚 Решённые задачи

- Настройка светлой и тёмной тем, которые сочетаются с ретро-палитрой и сохраняются между сессиями.
- Согласование состояний между сердцем SVG и текстом кнопки с нужным таймингом (`setTimeout`).
- Работа с прозрачностью (`mix-blend-mode`, тени, stroke), чтобы подписи оставались читаемыми.
- Сохранение визуальной иерархии при фиксированной ширине контента и гибких отступах.
- Чёткая структура файлов, чтобы проект было удобно поддерживать и развивать.
